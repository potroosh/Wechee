# WECHEE

Bilingual (FA / EN) landing site for WECHEE digital marketing & social media services.

- `index.html` Home, `services.html` Services, `about.html` About us
- All text lives in `js/i18n.js` (fa / en)
- Hero/about photo: `assets/photo.jpg`
- WhatsApp link: `js/main.js` (`WA_LINK`)

Static site, no build step. Hosted with GitHub Pages.
